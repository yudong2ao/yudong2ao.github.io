> **让你的官方 draw.io 桌面端焕然一新！**
> 注入无边框现代化窗口、消灭启动白屏闪烁，实现沉浸纯净的绘图体验。

## 前言

作为一名重度流程图和架构图绘制用户，[draw.io](https://www.drawio.com/)（Diagrams.net）桌面版一直是我不可或缺的生产力工具。它开源、纯粹，无需强制云端同步，绘制架构图和技术拓扑极其顺手。

然而在 Windows 平台下，官方桌面客户端的视觉体验一直有些“差强人意”：

1. **传统的突兀标题栏**：在现代 Windows 11 的圆角悬浮审美下，官方顶部白色的传统系统标题栏显得十分割裂；
2. **刺眼的冷启动白屏**：开启深色模式时，每次启动软件总会先闪过一片生硬的大白屏过渡页；
3. **深浅色主题脱节**：系统切换为深色主题后，软件窗口的标题与控件无法自动平滑过渡，缺乏一体感。

既然官方暂未优化，作为开发者，最好的办法就是亲自动手改造它。于是有了这个针对 draw.io 桌面版的注入优化补丁 —— **Drawio Patcher**。

## 核心特性

- 🖥️ **现代化无边框 (Frameless Window)**：精简窗口层级，彻底移除顶部系统标题栏，工作区利用率大幅提升；
- 🌗 **主题配色深度自适应**：智能感知 Windows 系统的配色模式，窗口控制按钮及边框在深色/浅色模式下自然融入背景；
- 🎨 **定制优雅 Splash Screen**：定制平滑的 draw.io 专属 Logo 动画，告别生硬白屏；
- ⚡ **闪电般的启动响应**：剔除冗余的联网升级探针，兼顾纯净度与启动响应速度，同时防止补丁在被自动更新覆盖。

## 安装与注入方式

补丁基于官方 **draw.io v30.2.6** 桌面客户端开发，提供两种开箱即用的注入方式：

### 方式一：Node.js 自动化脚本一键注入（推荐）

如果本地已配置 Node.js 环境，脚本会自动扫描 draw.io 安装路径、安全备份原版 `app.asar`，并完成补丁热注入：

1. 克隆或下载本项目至本地；
2. 打开管理员权限的 PowerShell 终端；
3. 进入工具目录，运行注入命令：
   ```bash
   node drawio-patcher.js
   ```
4. 脚本会自动将原文件安全备份为 `app.asar.bak`，秒级完成美化注入。

### 方式二：直接替换补丁包（免环境极速版）

如果不希望安装任何环境，可以直接在 Releases 中下载打包好的补丁文件：

1. 找到 draw.io 安装目录下的 `resources` 文件夹；
2. 将原版 `app.asar` 重命名为 `app.asar.bak`；
3. 将下载的优化补丁直接放入该目录即可。
