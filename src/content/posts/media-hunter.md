> **核心理念**：拒绝臃肿的 GUI 客户端，拒绝浏览器的下载沙盒限制。让极客工具回归“静默、高效、安全、高度可配”的本质。

## 前言

在日常浏览网页、查阅资料或者学习时，我们经常需要将网页中的音视频资源离线保存下来。市面上常见的解决方案无非两种：

1. **浏览器扩展（插件）**：虽然嗅探方便，但受限于浏览器自身的沙盒机制，既无法直接调用多线程并发加速，也难以处理复杂的签名解密与音视频合并，大文件还容易让标签页崩溃；
2. **桌面 GUI 下载软件**：虽然功能齐全，但通常体积庞大、常驻后台耗费内存，且每次复制粘贴链接的交互流程非常割裂繁琐。

能不能兼得两者的优势——**既保留浏览器插件“点击即嗅探”的便捷，又拥有原生下载引擎（yt-dlp/ffmpeg）的强悍性能与多线程能力，同时还不被丑陋庞大的界面打扰？**

带着这个思考，我构建了 **MediaHunter（媒体猎手）**。

---

## 架构设计：跳出沙盒的协同系统

MediaHunter 并没有走传统的单体软件路线，而是采用了**“前端轻量感知 + 本地服务网关 + 原生系统通知”**的协同架构：

```text
┌─────────────────┐       Local API (HTTP)       ┌────────────────────────┐
│  浏览器网页     │ ───────────────────────────> │  本地静默网关服务      │
│ (Tampermonkey)  │                              │ (yt-dlp + ffmpeg/deno) │
└─────────────────┘                              └───────────┬────────────┘
         ▲                                                   │
         │                                                   ▼
 浮动按钮轻量提示                                      Windows 原生通知中心
 (弱提醒：下载中)                                  (按需查进度 Win+N / 完成强弹窗)
```

1. **前端（Tampermonkey 油猴脚本）**：负责网页媒体资源的实时嗅探、清晰度选项提取与悬浮面板呈现；
2. **后端网关（Local API Server）**：在本地后台轻量静默运行，接收前端派发的下载指令，调度 `yt-dlp`、`ffmpeg` 和 `deno` 引擎执行高并发下载与合成；
3. **系统反馈（Windows 原生 Toast 通知）**：直接接入 Windows 系统的操作中心（Action Center），实现原生体验。

---

## 交互美学：克制的“弱提醒”与“按需反馈”

很多下载软件动辄弹窗闪烁、抢占焦点，体验极其干扰。在 MediaHunter 的交互设计上，我坚持了极度克制的原则：

- **零打扰弱提醒**：在网页端点击“下载”后，悬浮按钮仅切换为灰度或“下载中”微动状态，绝不阻断当前浏览体验；
- **按需查看进度**：如果想知道下载进度，无需切换窗口，只需随时按下 <kbd>Win</kbd> + <kbd>N</kbd> 呼出 Windows 系统通知中心，即可在系统原生面板中查阅实时下载百分比与速度进度条；
- **关键节点强提醒**：仅在**“下载完成”**或**“下载异常”**的关键节点，才在屏幕右下角触发系统级横幅通知，并支持一键打开下载文件夹。

## 核心特性

- 🎯 **嗅探全面**：自动识别主流平台流媒体、常见格式音频视频及动态加载流；
- ⚡ **无感静默**：后台网关由极简脚本拉起，无命令行黑框常驻，内存占用微乎其微；
- 📦 **双分发模式**：
  - **全能集成包 (`MediaHunter-Full`)**：开箱即用，内置集成了 `yt-dlp.exe`、`ffmpeg.exe` 以及免安装解密引擎 `deno.exe`；
  - **纯净轻量包 (`MediaHunter-Lite`)**：适合极客玩家，仅保留核心网关脚本，自由指定系统全局依赖；
- 🛡️ **Win11 深度兼容**：针对 Windows 11 24H2（移除默认 VBScript）进行了环境自检与引导提示。

## 快速上手

### 1. 部署本地网关

下载打包好的集成包解压至任意目录（例如 `D:\MediaHunter\`），双击运行目录下的 `StartServer.vbs`，本地网关即在后台静默就绪。

> **Windows 11 24H2 提示**：若双击 `.vbs` 无反应，请前往系统“设置 → 系统 → 可选功能”中搜索并安装 **VBScript**。

### 2. 安装浏览器脚本

在浏览器扩展商店安装 [Tampermonkey](https://www.tampermonkey.net/)，导入项目中的 `MediaHunter-8.3.7.user.js` 并启用。

刷新任意视频网页，页面右下角将出现紫色的 **「媒体猎手」** 悬浮胶囊，点击即可呼出嗅探解析菜单，开启丝滑下载！
