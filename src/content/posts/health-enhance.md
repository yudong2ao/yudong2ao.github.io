> **核心哲学**：拒绝机械死板的倒计时闹钟。只在“真正连续工作”时提醒，短暂停顿不误判，原生 Win11 Toast 守护打工人健康。

## 前言

作为一名长期伏案的开发者，在工位上一坐就是一个上午或整个下午是家常便饭。久坐对身体的摧残是潜移默化的，颈椎酸痛、腰肌劳损，更严重的是成年男性的前列腺健康和尿路健康深受其害。

为了拯救自己的腰与健康，我曾尝试过市面上几乎所有所谓的“久坐提醒”或“番茄钟”软件，但很快就全被我卸载了。因为它们大多存在致命的体验痛点：

1. **死板的机械计时**：只是定个倒计时闹钟，根本不管你是不是刚离开工位去开了个半小时的会、刚接完水回来。你刚坐下 5 分钟，它就突兀地响起来提醒你“该休息了”；
2. **粗暴地打断心流**：很多软件动辄全屏锁定、强行弹出刺眼的遮罩，在代码灵感迸发的关键时刻瞬间打碎思路；
3. **臃肿常驻内存**：一个简单的提醒功能动辄打包了整个 Electron 框架，开机后台常驻几十上百兆内存。

既然市面上的工具都不尽如人意，极客最好的解决办法就是**自己动手写一个真正符合人类工作直觉的健康守护脚本** —— **HealthEnhance**。

## 状态判定：像真人一样理解“连续专注”

HealthEnhance 的核心，在于它**不是靠死板的倒计时，而是根据鼠标与键盘的真实底层交互时序来智能推理工作状态**：

```text
               ┌────────────────────────┐
               │    监听系统全局输入     │
               │ (Win32 GetLastInputInfo)│
               └───────────┬────────────┘
                           │
           ┌───────────────┴───────────────┐
           ▼                               ▼
    [检测到键鼠活动]                 [键鼠完全无活动]
           │                               │
   计算真实物理流逝时间               空闲时间累加
           │                               │
  物理中断是否 ≥ 5 分钟？           空闲时长是否 ≥ 5 分钟？
     ├── 是 ──> 重置工作计时(已休息) ├── 是 ──> 重置工作计时(视为休息)
     └── 否 ──> 累计连续工时         └── 否 ──> 保持当前工时计时
           │
 连续工作累计达到 60 分钟？
     └── 是 ──> 触发 Windows 原生 Toast 提醒 (5 秒自隐)
```

1. **真实工作判定**：只要键盘或鼠标处于活跃状态，就判定为处于工作专注期；
2. **防抖与短暂停顿容错**：起身上个洗手间、喝口水（中断离开不足 5 分钟），回到座位后**不会重置计时**，依然严谨累计连续工时；
3. **真正的休息重置**：如果离开工位超过 5 分钟（无论中途去开会、午休，还是电脑睡眠合盖），脚本自动判定你已经完成了阶段性休息，连续工作计时归零，重新开启下一轮守护。

## 核心技术实现：轻巧与硬核并存

整个脚本不到百行，却在底层细节上做了极为考究的设计：

### 1. Win32 原生 API 零侵入监听

通过 PowerShell 内嵌 C# P/Invoke 调用 `user32.dll` 的 `GetLastInputInfo`。无需注入全局键盘钩子，也无需任何管理员权限，直接读取系统内核的最后输入时间戳，CPU 占用近似 0.00%。

### 2. 真实物理时钟与系统休眠感知

为了防止电脑合盖睡眠或挂起时时间被误判，脚本采用对比真实时钟差值：

```powershell
# 如果两次检查之间真实流逝的物理时间超过 5 分钟，说明系统刚从休眠/睡眠中唤醒
if ($realTimePassed -ge $IdleLimit) {
    $WorkTime = 0 # 视为已经休息，工作计时安全清零
    continue
}
```

### 3. Windows Runtime (WinRT) 原生通知

抛弃老旧脆弱的 `NotifyIcon` 气球提示，直接调用 Windows 10/11 底层运行时 `Windows.UI.Notifications.ToastNotificationManager`。同时对通知文本中的 XML 特殊字符做实体安全转义，原生支持自定义 Logo 渲染。

## 快速上手与开机自启

脚本基于相对路径设计，下载即用，无需配置系统环境：

### 1. 下载项目

下载项目包解压至任意目录（例如 `D:\Tools\HealthEnhance\`）。

> **个性化建议**：你可以直接替换同目录下的 `icon.png` 更换成自己喜欢的头像或提醒图标。

### 2. 配置开机自启（推荐）

1. 找到目录下的 `HideRunHE.vbs` 文件，右键选择“创建快捷方式”；
2. 按下快捷键 <kbd>Win</kbd> + <kbd>R</kbd>，输入：
   ```text
   shell:startup
   ```
   回车打开当前用户的开机自启目录；
3. 将刚才创建的快捷方式粘贴到此文件夹中。

### 3. 立即运行

双击运行 `HideRunHE.vbs`，脚本会以隐藏无黑框的形式在后台静默运行，守护你的健康。

## ⚙️ 灵活参数调优

默认配置为**连续工作 60 分钟提醒，离开 5 分钟判定为休息**。如果你有属于自己的番茄工作节奏，只需用记事本打开 `HealthEnhance.ps1` 修改顶部阈值即可：

```powershell
$IdleLimit = 300   # 空闲判定阈值（秒，默认 5 分钟）
$WorkLimit = 3600  # 连续工作时间阈值（秒，默认 60 分钟）
```
